设置与诊断

浏览器稳定版无法扫描广播，此处用于校验解析公式或配合实验性扫描使用。

安卓实机使用说明 首次部署照做一遍，之后点「启动智能助手」即可

一、拿到 HTTPS 网址（三选一，推荐 A）

  1. A · Vercel（最省事）：把本文件 index.html 放进 GitHub 仓库根目录 → vercel.com 登录 → Add New → Project → Import 该仓库 → Framework 选 Other、其余默认 → Deploy，得到 https://xxx.vercel.app。也可在电脑上执行 npx vercel --prod 直接部署当前目录。
  2. B · GitHub Pages：仓库 Settings → Pages → Deploy from a branch → main / root → 得到 https://用户名.github.io/仓库名/。免费版要求公开仓库，而本文件内含和风 API Key，公开即等于泄露；介意就改用 A。
  3. C · Termux 本机（零公网、零证书、零电脑）：安卓机装 Termux，把 index.html 放到家目录，执行 pkg install python -y 再执行 python -m http.server 8080，Chrome 打开 http://localhost:8080/index.html。localhost 被 Chrome 视为安全上下文，蓝牙 / GPS / 常亮全部可用，也不依赖家里电脑开机；只有天气接口仍需手机蜂窝联网。
不能直接用 file:// 打开，也不能用 http://192.168.x.x：两者都不是安全上下文，Web Bluetooth / Geolocation / Wake Lock 会被 Chrome 禁用。页面顶部出现红色警告条就是这个原因。

二、手机上开权限（只做一次）

  1. 用独立的 Google Chrome（不是微信 / QQ / UC 内置浏览器），系统需 Android 6+。
  2. 系统设置里打开蓝牙和位置信息，定位模式设为「高精度 / 仅 GPS」。BLE 扫描依赖系统定位开关，只给网页权限不够。
  3. Android 12+：设置 → 应用 → Chrome → 权限 → 附近的设备允许；Android 11 及以下则是位置信息允许。
  4. Chrome 打开网址后：地址栏左侧锁形图标 → 网站设置 → 蓝牙与位置信息都设为允许；再点 Chrome 菜单 → 添加到主屏幕，以后一键打开。
  5. 中文语音包：系统设置 → 语言和输入法 → 文字转语音（TTS）→ 安装「中文（中国）」语音数据。没有中文 TTS，zh-CN 会完全无声；国产 ROM 若不带 Google TTS，需先装「Google 文字转语音引擎」或改用系统自带中文引擎。

三、上车使用

  1. 手机插车充、横放支架上；关掉省电模式，并把「充电时屏幕永不休眠」打开做兜底。
  2. 点 ▶ 启动智能助手（必须是用户手势，这一步同时解锁 TTS / 申请常亮 / 弹蓝牙选择器 / 请求定位）→ 在弹窗里选 LYWSD03MMC；刷过 pvvx 固件则选 ATC_xxxx。
  3. 顶部状态灯变「已连接」后，在中部控制区手动点选当前车机的真实档位（温度格 / 风量 / 内外循环 / AC）。算法按你填的状态算差值，填错就会给错建议。
  4. 之后自动运行：每 1 分钟或温度变化 ≥0.5℃ 算一次；车内 24±1.5℃ 内保持静默；每条建议后 5 分钟冷静期不重复播报。
  5. 不要按电源键锁屏。Wake Lock 只防自动息屏，锁屏后 Chrome 会挂起 JS；切走再回来会自动重新申请常亮。

四、排障

  • 连不上蓝牙：确认传感器没被别的手机 / 米家 App 占着连接，点「连接 / 重连蓝牙」重试；某些原厂批次需先在系统蓝牙里配对一次。仍不行可用桌面 Chrome 刷 pvvx 明文固件（本页兼容 ATC_ / LYWSD03 / BTHome）。
  • 天气一直不更新：位移 <3km 且 <10 分钟会主动跳过以省配额，点「刷新天气」可强制；隧道 / 无网会回落 Open-Meteo 或保留上次数据，不影响温度判断。
  • 没有声音：先点「重播上条建议」验证 TTS，再检查媒体音量、中文语音包、静音 / 勿扰。
  • 页面里明文写着 API Key，任何能打开该网址的人都能查看源码。仅建议自用；对外使用请改成后端代理或换成无 Key 的 Open-Meteo。
